# Training Battle 2.0 — PWA-пакет

## Что внутри
- `index.html` — ваша игра с добавленными ссылкой на manifest и регистрацией Service Worker.
- `manifest.json` — название, цвета, режим отдельного окна и иконки для установки.
- `sw.js` — кеширование оболочки приложения для повторного запуска офлайн.
- `icons/` — иконки 192×192 и 512×512.

## Публикация бесплатно через GitHub Pages
1. Распакуйте ZIP и создайте публичный репозиторий GitHub, например `training-battle`.
2. Загрузите в корень репозитория `index.html`, `manifest.json`, `sw.js` и папку `icons` (не загружайте сам ZIP вместо этих файлов).
3. Откройте репозиторий → **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем **Save**.
5. Дождитесь URL вида `https://ВАШ-ЛОГИН.github.io/training-battle/`.
6. Откройте URL на телефоне/компьютере и проверьте, что браузер предлагает установку или пункт **Install app / Добавить на главный экран**.

## Проверка офлайн
1. Сначала откройте игру онлайн и дождитесь полной загрузки.
2. Перезапустите её один раз, чтобы Service Worker установился и заполнил кеш.
3. В DevTools → Application → Service Workers убедитесь, что он активен; затем включите Offline и перезагрузите страницу.
4. На телефоне откройте установленную игру в авиарежиме.

## Важные ограничения, которые надо проверить
- В исходном HTML используются Google Fonts. Без сети игра должна работать с системными запасными шрифтами, но внешние шрифты могут не загрузиться офлайн.
- Прогресс и слова сохраняются через `localStorage`, то есть отдельно на каждом устройстве и в каждом браузерном профиле; автоматической синхронизации между устройствами нет.
- Service Worker требует HTTPS (GitHub Pages выдаёт HTTPS) или localhost для разработки.
- Это стартовая PWA-обвязка, а не гарантия полного QA. Перед публичным анонсом протестируйте все экраны, импорт/экспорт, сохранение прогресса и мобильные размеры.
